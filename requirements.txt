# Fully pinned, including transitive dependencies.
#
# This file used to pin only the direct dependencies. That is not enough: with
# `typer==0.12.5` and no pin on click, a rebuild months later pulled click 8.4,
# which typer 0.12 does not support, and the container died on startup with
# "Secondary flag is not valid for non-boolean flag" before serving a single
# request. A half-pinned requirements file is a build that works until it
# silently doesn't.
#
# Regenerate after changing anything:
#   python3.12 -m venv .venv && .venv/bin/pip install -r requirements.in
#   .venv/bin/pip freeze > requirements.txt
# then run the test suite *inside that venv*, not against whatever your machine
# happens to have installed.
